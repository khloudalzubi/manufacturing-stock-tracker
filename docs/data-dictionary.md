# Data Dictionary

This tool creates three main processed CSV outputs from Twelve Data responses. Raw API responses are saved under `data/raw/` as JSON evidence. Processed analysis files are saved under `data/processed/`.

The default watchlist used in examples is `CAT,DE,HON,GE,MMM`, representing large manufacturing and industrial companies.

## `manufacturing_watchlist_quotes.csv`

Current quote output created by:

```bash
uv run manufacturing-stock-tracker --symbols CAT,DE,HON,GE,MMM
```

Source: Twelve Data `/quote` endpoint. Each row is one symbol at the time of collection.

| Field | Type | Units / Values | Source and provenance | Missing-value rule | Transformation |
| --- | --- | --- | --- | --- | --- |
| `collected_at` | string | UTC ISO 8601 timestamp | Generated by this project when converting the API response | Required | Current UTC time at processing, rounded to seconds |
| `symbol` | string | Uppercase ticker | Twelve Data quote response | Required | Converted to uppercase |
| `name` | string | Company/security name | Twelve Data quote response | May be blank if unavailable | None |
| `exchange` | string | Exchange code/name, such as `NYSE` or `NASDAQ` | Twelve Data quote response | May be blank if unavailable | None |
| `currency` | string | ISO-style currency code, usually `USD` | Twelve Data quote response | May be blank if unavailable | None |
| `datetime` | string | Market date/time string from provider | Twelve Data quote response | May be blank if unavailable | None |
| `price` | float | Currency per share | Twelve Data `close` field in quote response | Required; invalid values fail validation | Renamed from provider `close` to `price` |
| `open` | float | Currency per share | Twelve Data quote response | May be blank if unavailable | Parsed from string/number to float |
| `high` | float | Currency per share | Twelve Data quote response | May be blank if unavailable | Parsed from string/number to float |
| `low` | float | Currency per share | Twelve Data quote response | May be blank if unavailable | Parsed from string/number to float |
| `volume` | integer | Shares traded | Twelve Data quote response | May be blank if unavailable | Parsed from string/number to integer |
| `previous_close` | float | Currency per share | Twelve Data quote response | May be blank if unavailable | Parsed from string/number to float |
| `change` | float | Currency per share | Twelve Data quote response | May be blank if unavailable | Parsed from string/number to float |
| `percent_change` | float | Percent | Twelve Data quote response | May be blank if unavailable | Parsed from string/number to float |
| `timestamp` | integer | Unix timestamp | Twelve Data quote response | May be blank if unavailable | Parsed from string/number to integer |

## `manufacturing_watchlist_history.csv`

Historical daily price output created by:

```bash
uv run manufacturing-stock-tracker --symbols CAT,DE,HON,GE,MMM --history --history-outputsize 30
```

Source: Twelve Data `/time_series` endpoint with `interval=1day`. Each row is one daily bar for one symbol.

| Field | Type | Units / Values | Source and provenance | Missing-value rule | Transformation |
| --- | --- | --- | --- | --- | --- |
| `collected_at` | string | UTC ISO 8601 timestamp | Generated by this project when converting the API response | Required | Current UTC time at processing, rounded to seconds |
| `symbol` | string | Uppercase ticker | Twelve Data time-series `meta.symbol` | Required | Converted to uppercase |
| `datetime` | string | Trading date | Twelve Data time-series bar | Required | Rows sorted ascending by date within each symbol |
| `open` | float | Currency per share | Twelve Data time-series bar | Required; invalid values fail validation | Parsed from string/number to float |
| `high` | float | Currency per share | Twelve Data time-series bar | Required; invalid values fail validation | Parsed from string/number to float |
| `low` | float | Currency per share | Twelve Data time-series bar | Required; invalid values fail validation | Parsed from string/number to float |
| `close` | float | Currency per share | Twelve Data time-series bar | Required; invalid values fail validation | Parsed from string/number to float |
| `volume` | integer | Shares traded | Twelve Data time-series bar | May be blank if unavailable | Parsed from string/number to integer |
| `interval` | string | `1day` for current workflow | Twelve Data time-series metadata | May be blank if unavailable | Copied from response metadata |
| `exchange` | string | Exchange code/name | Twelve Data time-series metadata | May be blank if unavailable | Copied from response metadata |
| `currency` | string | Currency code, usually `USD` | Twelve Data time-series metadata | May be blank if unavailable | Copied from response metadata |

## `manufacturing_watchlist_momentum.csv`

Momentum summary output derived from `manufacturing_watchlist_history.csv`. Each row is one symbol's return over the collected historical period.

| Field | Type | Units / Values | Source and provenance | Missing-value rule | Transformation |
| --- | --- | --- | --- | --- | --- |
| `symbol` | string | Uppercase ticker | Derived from processed historical rows | Required | Grouped by symbol |
| `start_datetime` | string | Trading date | Earliest historical row for the symbol | Required | Minimum date after sorting rows ascending |
| `end_datetime` | string | Trading date | Latest historical row for the symbol | Required | Maximum date after sorting rows ascending |
| `start_close` | float | Currency per share | Earliest `close` value for the symbol | Required; zero fails calculation | Used as return denominator |
| `end_close` | float | Currency per share | Latest `close` value for the symbol | Required | Used as return numerator |
| `period_return_percent` | float | Percent | Derived by this project | Required | `((end_close - start_close) / start_close) * 100` |
| `price_range_percent` | float | Percent | Derived by this project | Required | `((max(close) - min(close)) / start_close) * 100` |
| `observations` | integer | Count of daily rows | Derived by this project | Required; must be at least 2 | Number of historical rows for the symbol |

## Data Quality Rules

- API keys are read from `.env` and are never written to processed CSV files.
- Raw responses are saved for evidence and reproducibility.
- Pydantic validates incoming quote and time-series structures before processing.
- Required numeric fields fail clearly when missing or not parseable.
- The pipeline checks that every requested symbol appears in returned processed rows.
- Momentum requires at least two historical rows per symbol.
- Momentum cannot be calculated when a symbol's starting close is zero.

## SQLite Database: `data/tracker.db`

The optional SQLite database stores repeated current-quote collection runs. It is generated local history and is ignored by Git. It does not store API keys.

Created by:

```bash
uv run manufacturing-stock-tracker --symbols CAT,DE,HON,GE,MMM --save-db
```

### `quote_runs`

| Field | Type | Units / Values | Source and provenance | Missing-value rule | Transformation |
| --- | --- | --- | --- | --- | --- |
| `id` | integer | SQLite primary key | Generated by SQLite | Required | Autoincremented run identifier |
| `collected_at` | string | UTC ISO 8601 timestamp | First processed quote row in the run | Required | Copied from processed quote rows |
| `symbols` | string | JSON list stored as text, displayed as comma-separated symbols | CLI/dashboard requested symbols | Required | Serialized to JSON for storage |
| `row_count` | integer | Count of saved quote rows | Processed quote summary | Required | Copied from `summarize()` output |
| `average_price` | float | Currency per share | Processed quote summary | Required | Copied from `summarize()` output |
| `average_percent_change` | float | Percent | Processed quote summary | May be null | Copied from `summarize()` output |
| `top_gainer_symbol` | string | Ticker | Processed quote summary | May be null | Copied from `summarize()` output |
| `top_decliner_symbol` | string | Ticker | Processed quote summary | May be null | Copied from `summarize()` output |
